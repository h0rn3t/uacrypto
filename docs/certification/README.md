# Досьє підготовки uacrypto до державної експертизи КЗІ

Виробник: **Укренерго цифрові рішення**.

Статус: проєкт технічних матеріалів для погодження з експертною установою.
Призначення цього комплекту — визначити межі бібліотеки, відтворювану конфігурацію
та критерії випробувань. Номер експертного висновку не присвоєно; ці документи
не надають права заявляти сертифікованість або кваліфікований статус засобу.

## Рішення до формального подання

| Питання | Поточний стан | Хто закриває |
|---|---|---|
| Виробник | Укренерго цифрові рішення; повні реквізити та відповідальну особу додати до заяви | виробник |
| Вид засобу, клас, категорії інформації | проєкт: програмна бібліотека-компонент; офіційну класифікацію не визначено | виробник і експертна установа |
| Затвердження ТЗ і потреба в ТУ | технічний проєкт є; рішення та підписи ще не отримано | замовник розроблення і виробник |
| Об'єкт експертизи | обрати незмінний реліз, кінцевий артефакт і систему, в яку бібліотека вбудовується | виробник і експертна установа |
| Джерело ентропії | джерело ОС через `crypto/rand.Reader` у проєкті; дослідження конкретної ОС/середовища не виконано | інтегратор і експертна установа |
| Самотестування та контроль цілісності | тестовий комплект є; виробничий механізм у складі кінцевого засобу визначається погодженим профілем | інтегратор і експертна установа |
| Звіти випробувань | локальні/CI результати збираються за методикою; експертний протокол не отримано | виробник і експертна установа |

Тести сумісності з ІІТ, cryptonite або UAPKI доводять лише перевірені властивості
конкретних випадків. Експертний висновок іншого продукту не поширюється на uacrypto.

## Нормативна прив'язка

- [Положення про державну експертизу КЗІ, редакція наказу №302 від 24.04.2026](https://zakon.rada.gov.ua/laws/show/z0721-26): порядок та орієнтовні матеріали для досліджень.
- [Технічний регламент засобів КЗІ, постанова №991](https://zakon.rada.gov.ua/laws/show/991-2020-%D0%BF): застосовність процедури оцінки відповідності визначається призначенням засобу.
- [Роз'яснення ДержНДІ щодо регламенту](https://csi.cip.gov.ua/uk/pages/tehnichnij-reglament): ДСТУ ISO/IEC 19790 та 24759 для відповідного маршруту оцінювання.

Цей комплект не присвоює клас або рівень гарантії та не підміняє погоджену
програму експертних досліджень. Дані, яких немає в репозиторії або які потребують
організаційного рішення, наведено у таблиці вище без вигаданих реквізитів.
